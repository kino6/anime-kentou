# アニメ視聴検討表

今期アニメの一覧に、原作・制作・放送局のポイント、PV・Wikipediaへのリンク、「観る／様子見／割愛」の投票を付けた静的サイトです。

## ファイル
- `index.html` … サイト本体
- `config.js` … 表示するシーズン、Supabase の接続先、注目ワード（声優・キーワード）の初期値
- `data/YYYY-MM.json` … シーズンごとの作品データ（ポイント、公式サイト・公式X・公式YouTube、キャスト、主なスタッフ）
- `supabase.sql` … 投票用のテーブルと関数（Supabase の SQL Editor で1回実行）

## 毎期の更新
1. `data/` に新しいシーズンのJSONを追加（例：`2027-01.json`）
2. `config.js` の `season` を書き換える

投票はシーズンごとに分かれて保存されます。

## 作品データの作り方（必須項目）
ポイントの先頭には、必ず **原作の掲載先** と **掲載年数** を入れます。

- 原作情報は `tools/sources_YYYY-MM.py` に1作品1行で書きます（種別・掲載先・出版社・開始年・終了年・補足）。
  - 終了年：連載中は `None`、完結は年、ゲームの発売など単発は `"-"`
  - 開始年が分からない場合は `None` にすると、サイト上で「要確認」と表示されます
  - 原作がない作品（アニメオリジナル）は種別を `"オリジナル"` にします
- `python3 tools/build_points.py YYYY-MM` を実行すると、`data/YYYY-MM.json` の各作品に `source` が入り、ポイントの先頭が
  「原作：漫画『週刊少年ジャンプ』（集英社）、2021〜2026年 完結（5年）。」の形に揃います。最後に「要確認」の一覧が出ます。
- 調べる順番の目安：アニメイトタイムズの作品欄の「原作」表記 → Wikipedia の基本情報（掲載誌・連載期間）→ 公式サイト・出版社のページ。
- Wikipedia は記事への直リンクです。記事名は `tools/wiki_YYYY-MM.py` に1作品1行で書きます（日本語版を優先、なければ他言語版、記事がなければ `None`）。
